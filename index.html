02 / THE TOOLKIT

Three algorithms. One graph.

Understand how each algorithm explores a network.

↔

Breadth-First Search

Explores neighbors level by level using a queue. Useful for finding the fewest edges in an unweighted graph.

TIME COMPLEXITYO(V + E)
↳

Depth-First Search

Follows one branch as far as possible before backtracking. Useful for connectivity and cycle exploration.

TIME COMPLEXITYO(V + E)
⌁

Dijkstra's Algorithm

Finds the shortest weighted path from a start node with non-negative edge weights.

TIME COMPLEXITYO((V + E) log V)*

*Typical implementation with a priority queue. V = vertices, E = edges.
